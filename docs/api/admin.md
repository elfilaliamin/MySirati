# Admin & Audit Log API

Administrative endpoints for user directory management, account status moderation, and append-only audit trail retrieval.

::: warning 404 Obscurity
These endpoints are protected by `requireAdmin`. Unauthenticated requests or requests from users with `role: 'user'` return `404 Not Found` to obscure administrative route presence (`DEC-001`).
:::

---

## 1. System Statistics
`GET /api/admin/stats`

Returns aggregated platform metrics:
- Total users and active users
- Total active share links and access counts
- Recent moderation activities

---

## 2. User Directory & Management
`GET /api/admin/users?page=1&limit=20&search=john`

Returns paginated user summaries.

### User Inspection
`GET /api/admin/users/:id`

Retrieves user profile and section counts for support and moderation. Passwords and secret keys are **never** returned.

### Suspend / Reactivate User
`PATCH /api/admin/users/:id/status`
```json
{
  "status": "suspended"
}
```
Suspension immediately blocks login and deactivates all public share links.

### Revoke All User Links
`POST /api/admin/users/:id/revoke-links`

Bulk revokes every active share key generated by the user.

---

## 3. Audit Log Retrieval
`GET /api/admin/audit-log?page=1&limit=50&action=SUSPEND_USER`

Returns paginated append-only records from `admin_audit_log` with the administrator's email, target user ID, and JSON metadata payload.
