# Share Links API

Endpoints for creating, listing, inspecting, regenerating, and revoking AI share links.

---

## 1. List Share Links
`GET /api/share-links`

Returns all share links generated by the user. Note that secret keys are **never returned**; only the `key_prefix` (e.g. `a1b2c3...`) is displayed.

---

## 2. Create Share Link
`POST /api/share-links`

Generates a new 32-byte cryptographic key, stores its SHA-256 hash, and returns the full plaintext URL **only once** in the response payload.

### Request Body
```json
{
  "name": "Anthropic AI Research Role",
  "config": {
    "includeEmail": false,
    "includePhone": false,
    "includeEducation": true,
    "includeExperiences": true,
    "includeProjects": true,
    "includeSkills": true,
    "includeLanguages": true,
    "selectedExperienceIds": ["exp_1", "exp_2"],
    "selectedProjectIds": ["proj_1"]
  },
  "expiresAt": "2026-12-31T23:59:59.000Z"
}
```

### Response (`201 Created`)
```json
{
  "success": true,
  "link": {
    "id": "link_1234...",
    "name": "Anthropic AI Research Role",
    "keyPrefix": "k8X2a9",
    "fullUrl": "https://mysirati.com/api/p?key=k8X2a910bf8a77d2e0984...",
    "secretKey": "k8X2a910bf8a77d2e0984..."
  }
}
```

---

## 3. Regenerate Key
`POST /api/share-links/:id/regenerate`

Generates a fresh 32-byte key for an existing link, updates the hash, and invalidates the previous key.

---

## 4. Revoke Link
`POST /api/share-links/:id/revoke`

Sets `revoked_at = NOW()`. Subsequent requests to `/api/p` with this key will return `404 Not Found`.
